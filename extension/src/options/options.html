Server & Zugang

Die Erweiterung verbindet sich mit dem Betreuungsbüro-Server. Das API-Token erstellen Sie in der Anwendung unter Nutzer-Menü → Erweiterungs-Zugänge (Online-Modus).

Lokale Fälle (ohne Server)

Für den Lokal-Modus der Anwendung: Importieren Sie eine Datensicherung.json eines Falls. Die Daten liegen dann NUR in dieser Erweiterung (storage.local dieses Browsers) – Löschen jederzeit möglich.

Angelernte Formulare

Büroweit trainierte Formular-Zuordnungen (Feld ↔ Datenschlüssel), gemeinsam mit dem Server verwaltet. Ansehen, umbenennen, URL-Muster anpassen, einzelne Felder entfernen oder ganz löschen. Verschobene Felder neu erfassen geht über „Training" im Panel auf der Live-Seite.

Ausfüllprotokolle

Jedes Ausfüllen wird als Eintrag in die Falldokumentation geschrieben – dort gehört es hin, neben den Rest der Fallhistorie. Hier liegen nur die letzten Läufe dieses Rechners zur Fehlersuche.

Darstellung

Das Panel folgt standardmäßig der Einstellung Ihres Systems. Hier lässt sich das festlegen.

Sicherung

Sichert Einstellungen (ohne API-Token), lokale Fälle, lokale Site-Profile, den Profil-Cache und die Ausfüllprotokoll-Historie als JSON – z. B. für einen Rechnerwechsel.
